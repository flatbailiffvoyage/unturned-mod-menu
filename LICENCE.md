## 🧩 About

**Unturned Mod Menu** is a curated list of Unturned open-source tools:

- **Overlays** — on-screen helpers, layout notes, item viewer, waypoint switcher
- **Quality-of-Life Helpers** — loot catalog, skin manager, overlay notes
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Waypoint Switcher — practice from any map marker
- Show Item Info — visualize loot and container info
- Map Notes — record and review exploration routes
- Time Scale — adjust single-player day cycle for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse items, skins, colors, effects
- Custom Skin Notes — organize player cosmetics
- Loot Table Notes — improved visibility of drop chances

### Aimbot
- Single-Player Notes — segment study on any map
- Base Layout Control — manually organize building placements in the editor
- Movement Buffer Notes — chain complex maneuvers in single-player
